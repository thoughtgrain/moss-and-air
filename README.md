# moss-and-air

## moss/

[Moss](moss/) is my fork of [Felucca](https://github.com/hugelton/Felucca), the GPL-3.0-only
replacement firmware for the M-VAVE FM-1 by Leo Kuroshita / Hügelton Instruments. It starts from
Felucca 1.0.3 (`b22a24b`), imported unmodified so every change after that is easy to see in the
history.

The thanks, and how I try to be a good downstream, are in
[moss/ACKNOWLEDGEMENTS.md](moss/ACKNOWLEDGEMENTS.md). The GPL modification notice is in
[moss/NOTICE.md](moss/NOTICE.md). Everything inside `moss/` is GPL-3.0-only, same as upstream.
